Pemetaan ke kertas kerja Export PPh21: Uang Jalan Kanvas → ditambahkan ke kolom Tunjangan/Cash Bon (di atas CASHBON+PIUTANG KANVAS dari payroll); Uang Konsumsi → Insentif/Tunjangan Lain; Subsidi/Lembur → Subsidi Pajak / Lembur; Bonus/THR → Bonus/THR. Import hanya mengisi tabel di layar — data baru tersimpan setelah tombol Simpan ditekan.
